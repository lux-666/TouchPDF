# 发布前验证

在项目根目录运行：

```sh
zsh build.sh /tmp/touchpdf-check
/tmp/touchpdf-check/TouchPDF.app/Contents/MacOS/TouchPDF --self-test /tmp/touchpdf-check.pdf
zsh package.sh
codesign --verify --deep --strict dist/TouchPDF.app
(cd dist && shasum -a 256 -c SHA256SUMS.txt)
```

界面回归必须使用副本和隔离的 bundle identifier，避免退出用户窗口或修改原 PDF。完成下面的实际文件打开检查后才算验证应用可用；仅验证空白画布和 PDF 数据解析不够。

1. 冷启动，启动选择框选择有效 PDF，点“打开”：显示对应文件的文档窗口，进程保持运行。
2. 从文档窗口按 ⌘O 再打开另一份 PDF：显示第二个文档，第一份保持打开。
3. 启动时打开无效 PDF：显示错误；关闭错误提示后能重新选择有效 PDF。
4. 启动时新建空白画布：窗口保留；关闭最后一个无修改文档后应用退出。
5. 启动时取消文件选择：应用退出。
6. 有未保存笔迹时 ⌘Q：保存提示正常；取消后可继续操作，保存后退出。
7. 同标识的另一副本启动：出现重复进程提示；请求正常退出后继续启动，不强杀进程。
8. X/Esc、单按 Shift、Shift 组合键和输入框状态：工具切换正确，输入文字不切换批注。

自检与界面自动化不能证明真实触控板的双指惯性、捏合、三指移动或轻压手感；这些需要硬件试用。

9. 暂停批注后用工具栏调框大小、居中、选笔/橡皮、颜色、落笔方式与力度；批注保持关闭；用 [ / ]、C、1–5 验证相同行为，恢复后设置保留，PDF 不变。

10. 单按钮在画笔/橡皮之间切换，X 行为一致；暂停时不自动开启批注，B/E 均不改变工具或批注状态。
11. 双栏点击“铺满”：蓝框覆盖整个阅读区（包括页缝），窗口变大变小时同步调整；再次点击恢复等比例框，滑块最大为 600%。
12. “笔设置”弹窗内容完整、不贴边；暂停时仍可操作，关闭弹窗后恢复原有输入模式。
13. Retina 显示器在 100%、适合宽度、双栏与缩放/滚动后查看笔迹：位置正确、没有残影。检查 InkSurface 图层 contentsScale 与窗口 backingScaleFactor 一致。
14. 自检实际渲染导出的 PDF，不能只检查 InkList 存在：抑制屏幕批注绘制可能造成 PDFKit 缓存空白外观。保存副本必须重建 TouchPDF Ink 外观，保存后屏幕绘制状态不变。

15. 橡皮轻触只定位：显示虚线范围圈和橙色整笔高亮，不删除；加力后变为红色并累计待擦数量，收笔一次删除、⌘Z 一次恢复。检查交叉/重叠笔迹、页缝和页外笔迹、缩放后的命中范围；预览高亮不进入导出的 PDF。
16. 检查工具按钮的 X、居中的 C、大小的 [ ]、打开/保存/撤销的 ⌘O/⌘S/⌘Z，以及底栏常驻提示；最小窗口下不能遮挡。
