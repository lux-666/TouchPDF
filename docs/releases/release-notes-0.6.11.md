# TouchPDF 0.6.11 — 简化工具栏、铺满书写区与 Retina 笔迹

- 工具栏收为两排，统一图标；画笔和橡皮共用一个按钮，点击或按 X 切换且保持批注开关。B / E 仍直接选笔 / 橡皮并开启批注。
- 力度、落笔方式、减力收笔和平滑移到“笔设置”弹窗；暂停批注时同样能调整。
- 等比例书写框上限由 300% 提高至 600%；新增“铺满”，映射到整个可见阅读区，跨双栏、页缝，不受触控板长宽比限制。再次点击恢复等比例框。铺满时横纵映射比例可能不同。
- TouchPDF 笔迹改用随显示器像素倍率绘制的矢量覆盖层，避开 PDFKit 的低分辨率批注缓存；滚动、缩放和双栏变化时重新绘制。
- 保存时在独立文档副本中重建笔迹外观，避免导出空白缓存；仍保存标准可编辑 PDF Ink，页外笔迹仍只在当前会话保留。
- 增加 100% 阅读按钮，保留原生双指滚动与捏合、三指移框、Shift 暂停和工具快捷键提示。

验证：完整自检通过，包含铺满四角映射、窗口尺寸变化、暂停工具切换、真实导出图像及跨页保存/撤销回归；隔离应用实际打开 PDF、单双栏、铺满、X 切换和设置弹窗检查。真实触控板压力和多指手感仍需硬件试用。

支持 Apple Silicon、macOS 13+；本地临时签名，尚未公证。
