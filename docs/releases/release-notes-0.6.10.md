# TouchPDF 0.6.10 — 用触控板调整工具与快捷键提示

暂停批注后可以直接使用触控板调整工具栏，不必接鼠标。

- 阅读模式下可预选笔/橡皮、调书写框大小、换颜色、设置落笔方式、力度与减力收笔；操作不会自动开始批注。
- 调整大小和居中显示书写框预览，再按 Shift 继续书写，保留选好的工具与参数。
- 工具栏分为阅读、批注工具和落笔设置三排；按钮、颜色菜单和状态栏显示常用快捷键；新增完整快捷键说明。

| 快捷键 | 操作 |
| --- | --- |
| Shift（单按松开） | 暂停 / 恢复触控板批注 |
| B / E | 选笔 / 橡皮并开启批注 |
| Esc | 返回阅读 |
| [ / ] | 书写框缩小 / 放大 10% |
| C | 书写框居中 |
| 1–5 | 蓝、黑、红、绿、紫 |

颜色、大小和居中快捷键不改变批注开关；输入框中不触发工具快捷键。

本次也包含此前本地 0.6.6–0.6.9 的更新：跨页独立画布、页缝/页外笔迹随 PDF 移动、三指移框、版本与进程识别、正常退出保存提示，以及启动选择 PDF 后意外退出的修复。PDF 保存只导出页内笔迹；页外笔迹仅在当前会话保留。

验证：完整自检通过，新增暂停状态下调工具、框预览、恢复设置及不修改 PDF 的检查；隔离应用实际打开 PDF、点击工具/滑块、颜色和大小快捷键、恢复批注、Esc、快捷键说明面板以及界面目视检查通过。自动检查不代替真实触控板手感和单独 Shift 硬件按键验证。

支持 Apple Silicon、macOS 13+。应用使用本地临时签名，尚未公证。下载 ZIP 与 SHA256SUMS.txt 可核对校验值。
