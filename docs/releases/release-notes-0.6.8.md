# TouchPDF 0.6.8 (15) — 本地固定入口与快捷键

- 项目根目录新增 `启动 TouchPDF 稳定版.command`，固定启动 `release/TouchPDF/dist/TouchPDF.app` 的新进程，避免复用旧进程。窗口标题和关于窗口显示编译版本；关于窗口显示运行路径。
- 新进程识别同一应用的其他运行实例，列出路径与 PID，可请求正常退出或取消本次启动。等待未完成时允许重新检查；不强制终止。
- 菜单提供退出当前应用（⌘Q）和退出所有 TouchPDF。未保存文档继续使用系统保存提示，取消则保留进程。关闭最后一个文档后退出；启动选择文件时取消也退出。
- 单按 Shift 并松开：开关触控板批注，保留工具选择。B 选笔，E 选橡皮，两者同时启用批注；Esc 返回阅读。输入框、保存面板与 Shift 组合键不触发切换。

## 验证

- 最终优化构建自检全部通过：Shift 状态机（单按/重复/组合键/编辑框/失焦）、工具切换（包括未收笔时切换工具仍提交原笔画/擦除），以及既有的跨页画布、页外笔迹、PDF 导入、单双栏切换、居中、保存裁切、撤销与输入恢复检查。
- 隔离应用的实际界面检查：B/E 与 Esc 状态正确，Shift+B 不误切换；带未保存笔迹的测试文档在 ⌘Q 后显示保存提示，取消后可继续切换工具；再次退出并保存到 `/tmp/touchpdf-068-quit-saved.pdf` 后进程退出。
- 同标识、不同路径的两个隔离应用验证重复启动提示，正常退出原实例后继续启动；取消新版启动文件面板后进程退出。
- arm64 架构、ad-hoc 签名严格校验、发布 ZIP 的 SHA-256 校验和启动脚本语法检查通过。

## 边界

界面自动化工具不支持发送单独 Shift，所以此键仅完成状态机验证，真实键盘仍需试按。既有双指/三指和力度手感也不能由自动检查代替。测试使用隔离应用和临时文档，没有关闭用户文档或修改原 PDF。本次仅本地打包，未发布 GitHub。页外笔迹仍只保留在当前会话，PDF 保存只导出页内部分。
