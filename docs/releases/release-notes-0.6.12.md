# TouchPDF 0.6.12 — 橡皮预览与可见快捷键

- 移除 B/E，只用 X 或同一个按钮切换画笔／橡皮；Shift 继续独立控制批注开关。
- 工具栏直接标出 X、C、[ ]、⌘O、⌘S、⌘Z；底栏常驻主要快捷键，并在橡皮模式显示操作说明。
- 橡皮显示固定屏幕大小的范围圈。轻触定位时，以橙色高亮会命中的完整笔画；加力擦除时，以红色高亮本次累计待擦的笔画，并显示“待擦 N 笔”。
- 收笔后执行整笔擦除，⌘Z 一次恢复。圈内重叠笔画一起选中，页缝及页外画布使用相同反馈，预览不会改变 PDF 或写入保存文件。

验证：完整自检通过，包括橡皮预览/待擦状态的实际离屏绘制、预览与删除一致、重叠笔迹、缩放、页外笔迹及一次撤销恢复；隔离应用实际打开 PDF，确认 B/E 无效、X 切换和可见快捷键排版。真实触控板压力手感仍需设备试用。

支持 Apple Silicon、macOS 13+；本地临时签名，尚未公证。
