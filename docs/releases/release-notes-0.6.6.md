# TouchPDF 0.6.6 — 本地修订

- 双指滚动与捏合进入 PDFKit/AppKit 原生事件链；移除手算捏合和 Command 滚轮缩放。保留原事件的方向、相位与惯性信息。
- 鼠标停在工具栏时，批注模式的导航事件也交给 PDF 内部原生滚动视图。
- 书写框仅使用屏幕覆盖层坐标；移到视窗边缘后不会被自动重置到中央。
- 笔画可以从页面外开始，穿越页面与页缝；收笔后页外部分仍保留，随 PDF 滚动和缩放。
- 页面内是标准 PDF 矢量批注，页外部分保留在当前会话；保存仅导出当前页面范围内的笔迹，保存不清除画布。关闭文档后页外部分不保留。
- 跨页笔画整笔撤销/重做；页缝可擦除。单双栏切换重新排版时，页外笔迹跟随起笔参考页。

验证：调试自检和优化版自检、PDF 保存重开、跨页裁切、重复保存、撤销重做、页缝擦除、视图坐标映射。临时测试窗口已目视确认跨页曲线连续，批注开启以及指针在工具栏时可滚动且缩放读数不变。

限制：未通过真实触控板实测捏合、惯性及轻压手感。UI 自动滚动不是硬件手势验收。该版本仅在本地打包，未发布到 GitHub。本地临时签名，未公证。
