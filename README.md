# TouchPDF

A lightweight macOS PDF reader and editor that turns your trackpad into a handwriting surface.

一个轻量的 macOS PDF 阅读与批注应用：触控板轻触定位、加力落笔，无需按下左键；手指位置绝对映射到独立书写框，抬手换位后可以自然地继续写公式。

## 工作区

当前工作区根目录就是 Git 仓库。目录与入口：

| 路径 | 内容 |
| --- | --- |
| `src/` | Swift 源码与触控板 C 桥接 |
| `resources/Info.plist` | 应用版本、文件类型与 bundle 配置 |
| `build.sh` / `package.sh` | 构建与打包，均从项目根目录运行 |
| `dist/` | 当前应用、ZIP 与校验文件，不进入 Git |
| `docs/releases/` | 各版本变更记录 |
| `docs/testing.md` | 发布前验证步骤，包含启动打开 PDF 回归 |
| `outputs/` | 两份用户笔记，保留原内容，不进入 Git |
| `archive/` | 旧发布包、研究源码、旧缓存与整理前清单，不进入 Git |
| `release/TouchPDF/dist` | 指向根目录 `dist/` 的兼容链接，原应用路径仍可用 |

双击 `启动 TouchPDF 稳定版.command` 启动当前构建。0.6.9 修复 0.6.8 从启动选择框打开 PDF 时意外退出的问题。关闭文件选择框与真正关闭最后一个文档现在分开处理。

工作区整理前的源码已建立独立快照提交。旧的空仓库元数据保存在 `archive/previous-empty-git/`；文件搬移清单与 SHA-256 清单也在 `archive/`。保留 GitHub origin 地址，发布时保留远端历史并同步源码。

## 下载

在 [Releases](https://github.com/lux-666/TouchPDF/releases) 下载最新的 `TouchPDF-*-macos-arm64.zip`，解压后将 `TouchPDF.app` 放到“应用程序”目录。

当前版本支持 **Apple Silicon（M 系列）及 macOS 13 或更新版本**。轻压绘画需要兼容的触控板，力度信号会随设备、手指姿势而变化，可用滑块调整门槛；不支持该输入时自动回退到“轻触即写”。Intel 构建尚未验证。

下载包使用临时本地签名，尚无 Developer ID 签名和苹果公证，首次运行可能被 macOS 拦截。也可以按下面的步骤从源码构建。

## 使用

本地固定入口为项目根目录的 `启动 TouchPDF 稳定版.command`，双击后从 `dist/TouchPDF.app` 启动新进程，避免复用仍在运行的旧程序。窗口标题与“关于 TouchPDF / 当前版本…”显示编译版本 `0.6.10 (17)`，关于窗口也显示实际运行路径。此入口固定指向本地当前构建；发布包见 GitHub Releases。

发现其他 TouchPDF 进程时，会列出进程与路径，可请求它们正常退出，或取消本次启动。未保存文档仍由系统提示保存；不会强制终止进程。通过“TouchPDF → 退出所有 TouchPDF”可向所有同标识进程发出正常退出请求；若任何窗口取消保存或退出，该进程会继续运行。`⌘Q` 退出当前应用，关闭最后一个文档后也会退出；启动选择文件时直接取消则退出。

1. 启动时选择 PDF，或选择“新建空白画布”。
2. 打开“触控板批注”，蓝色虚线框就是触控板对应的书写区域；鼠标点击放置框，左键拖动移框。点击“居中 C”可直接把框放在阅读视窗中央，包括双栏页缝。
3. 要调整工具栏，单按 Shift 暂停批注；用触控板点击笔/橡皮、颜色、大小和落笔设置，再按 Shift 继续。阅读模式调整大小或居中时只显示预览，不捕获触控板输入。
4. 在“轻压绘画”模式下轻触预览笔尖，加力落笔；无需物理点击或按住 Command。默认开始门槛 30，减力收笔门槛为开始门槛的一半。这些数值是原始信号单位，不是克数。

| 操作 | 行为 |
| --- | --- |
| 单指轻触、加力 | 预览、落笔；抬手结束当前笔画 |
| 勾选“减力收笔” | 减力结束笔画并继续定位，再次加力开始新笔画 |
| 取消“减力收笔” | 加力起笔后持续书写，直到抬手 |
| 双指上下/左右滑动 | 使用 macOS 原生滚动惯性滚动或平移 PDF 阅读视口 |
| 双指捏合 | 缩放 PDF |
| 三指移动 | 移动书写框；全部抬手后恢复双指导航或单指书写 |
| 书写框大小 40–300% | 独立调整映射区域，仅受当前视窗尺寸限制 |
| 鼠标滚轮 / 中键或右键拖动 | 滚动 / 平移 PDF |
| 单按 Shift 后松开 | 开关触控板批注，保留当前笔/橡皮选择 |
| B / E | 选择笔 / 橡皮，同时开启批注 |
| [ / ] | 缩小 / 放大书写框，每次 10%，不改变批注开关 |
| C | 书写框居中，不改变批注开关 |
| 1 / 2 / 3 / 4 / 5 | 蓝 / 黑 / 红 / 绿 / 紫，不改变批注开关 |
| Esc | 返回阅读模式 |

书写框是独立的连续屏幕覆盖层，单栏、双栏都可以跨页边、页缝和页面外背景；触控板映射不按页边硬切。书写框固定在视窗中，笔迹随 PDF 滚动和缩放。页缝与页外笔迹收笔后仍保留在当前会话，支持擦除、撤销和重做。保存时仅导出实际落在 PDF 页面内的部分；页外笔迹不会写入 PDF，关闭后不保留。保存不会清除当前画布。切换单双栏会重新排版页面，页外笔迹跟随起笔时的参考页移动。

触摸期间固定系统箭头，包括外接鼠标；全部抬手或应用失焦后恢复。多指退回单指时，需要全部抬手再继续书写，避免误落笔。系统三指手势可能与应用手势冲突。

支持蓝、黑、红、绿、紫和自定义笔颜色；默认启用“笔迹平滑”，保留细小移动与公式尖角。笔迹保存为标准 PDF 矢量 Ink 批注，支持整笔橡皮、撤销/重做、保存和另存为。颜色、力度、减力收笔和平滑设置会记住；颜色和平滑只影响新笔画。

单按 Shift 在松开时生效；Shift 组合键、输入框、保存对话框和失去焦点时不会触发批注切换。工具快捷键不拦截输入框中的文字。工具栏按阅读、批注工具、落笔设置分组；点击“快捷键 ?”查看完整说明。点击笔/橡皮按钮只预选工具，B/E 则选择工具并开始批注。

快捷键：`⌘O` 打开 PDF，`⌘N` 新建空白画布，`⌘S` 保存，`⇧⌘S` 另存为，`⌘Z` 撤销，`⇧⌘Z` 重做，`⌘W` 关闭文档，`⌘Q` 退出当前应用。

## 从源码构建

需要 Xcode Command Line Tools，没有第三方运行时依赖。

```sh
git clone https://github.com/lux-666/TouchPDF.git
cd TouchPDF
zsh build.sh
open dist/TouchPDF.app
```

打包发布文件：

```sh
zsh package.sh
```

产物位于 `dist/`，包含应用、ZIP 和 SHA-256 校验文件。构建缓存位于 `.build/`，这些文件都不会进入 Git。

## 验证

从“帮助 → 运行自检”检查输入状态机和 PDF 保存重开。结果写入 `~/Library/Application Support/TouchPDF/Checks/`，不改动当前文档。

检查还覆盖单独 Shift 与组合键/编辑框/焦点状态隔离、笔/橡皮切换。检查覆盖减力/抬手收笔、门槛滞回、绝对坐标与断笔、多指和输入中断恢复、指针释放、细小移动采样、公式尖角、彩色平滑笔迹保存重开及擦除、书写框与 PDF 独立缩放、撤销/重做。新增真实双栏视图层级、跳过页缝采样的跨页裁切、页外收笔保留、随文档变换、跨页整笔撤销/重做、页缝擦除、保存裁切及重复保存检查。自动检查和 UI 滚动验证不能替代真实触控板的捏合、惯性与轻压手感验证。

## 实现

Swift、AppKit、PDFKit 和一个小型 C 桥接。轻触即写使用公开 `NSTouch.normalizedPosition`。轻压模式动态加载私有 `MultitouchSupport.framework`，读取手指位置和未公开标定的力度相关字段，以不同起笔/收笔门槛抑制临界抖动。

笔迹位置不依赖鼠标坐标，不模拟左键，不修改系统触感或手势设置。原始输入仅由前台文档处理，不记录其他应用的输入。输入中断或私有接口不可用时恢复指针并回退；私有接口对未来 macOS 的兼容性没有保证，也不适用于正常 Mac App Store 上架。
