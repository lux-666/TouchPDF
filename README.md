## 为触控板手写而设计

TouchPDF 让 Mac 触控板成为随手可用的书写工具。手写、翻阅、缩放、擦除和工具调整，都可以在触控板上完成，无需在鼠标和触控板之间来回切换。

**轻压手写、连续落笔、自由换位。** 从公式符号到解题草稿，把思路直接写进 PDF，让手写成为电脑阅读的一部分。

## 刷题、上课、阅读，都能随手写

| 场景 | 用 TouchPDF 完成 |
| --- | --- |
| **刷题练习** | 圈出题目条件，手写计算过程，画辅助图，整理错题批注。 |
| **课堂笔记** | 在 PDF 讲义上补公式、记推导，标出老师强调的重点。 |
| **论文与教材** | 划线、圈注、画箭头，把理解和疑问留在原文旁。 |
| **随手草稿** | 新建空白画布，写算式、画草图，记录临时思路。 |

## 写得自由，也看得清楚

- **跨页书写**：单栏、双栏都能批注，书写区可跨页边和页缝。
- **清晰笔迹**：彩色手写、笔迹平滑、公式尖角保留，支持 Retina 显示。
- **可视擦除**：高亮将被擦除的笔画，支持撤销和重做。
- **灵活阅读**：连续阅读、双栏排版、滚动和缩放，与批注配合使用。
- **个性化书写**：可调力度、书写范围和笔颜色，适应不同书写习惯。
- **PDF 保存**：笔迹保存为矢量批注，可在系统“预览”等阅读器中查看。

![TouchPDF：双栏阅读与跨页书写区](docs/images/two-pages.png)

页内笔迹会保存；页缝和页面外可作临时草稿，仅在当前会话保留。

## 下载与安装

[**下载 TouchPDF for Mac**](https://github.com/lux-666/TouchPDF/releases/download/v0.6.13/TouchPDF-0.6.13-macos-arm64.zip)，解压后将 **TouchPDF.app** 拖入“应用程序”，双击打开。

首次打开若被 macOS 拦截，前往 **系统设置 → 隐私与安全性**，找到 TouchPDF，点击 **“仍要打开”**，按系统提示确认。该选项会在尝试打开 App 后出现。
