## 能做什么

| 阅读与书写 | 使用体验 |
| --- | --- |
| **轻压手写** | 轻触移动笔尖，加力书写，无需按下触控板；支持减力收笔或抬手收笔。 |
| **自由跨页** | 独立书写框可以横跨双栏、页缝和页面外，不按页边切割触控板。 |
| **原生导航** | 双指滚动、捏合缩放，三指移动书写框。 |
| **清晰笔迹** | Retina 笔迹绘制，支持颜色和平滑，保存为标准 PDF 矢量 Ink 批注。 |
| **可视橡皮** | 范围圈定位，橙色预览、红色待擦高亮；整笔擦除，可撤销。 |
| **键盘配合** | Shift 暂停／继续，X 切换画笔／橡皮；主要快捷键直接显示在界面上。 |

## 下载与安装

1. 前往 [最新 Release](https://github.com/lux-666/TouchPDF/releases/latest)，下载 `TouchPDF-版本号-macos-arm64.zip`。
2. 解压，将 `TouchPDF.app` 放到“应用程序”目录，双击启动。
3. 选择自己的 PDF，或新建空白画布。

支持 **Apple Silicon（M 系列）和 macOS 13+**，Intel 构建尚未验证。轻压绘画需要兼容触控板；不可用时会回退到“轻触即写”。

应用目前使用本地临时签名，尚无 Developer ID 签名和苹果公证，首次启动可能被 macOS 拦截。也可以[从源码构建](#从源码构建)。每个 Release 附带 `SHA256SUMS.txt`，可与 ZIP 放在同一目录校验：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 快速上手

1. **打开 PDF。** 根据需要切换单栏或双栏，调整阅读缩放。
2. **单按 Shift，松开后开始批注。** 蓝色虚线框就是触控板映射到的区域；手指位置对应框内位置。
3. **轻触定位，加力落笔。** 默认采用轻压模式，不需要物理点击；抬手后可以重新定位。
4. **按 Shift 暂停，再调工具。** 用触控板就能换颜色、调书写框和“笔设置”；调好后再按 Shift 继续。
5. **按 X 换橡皮，⌘S 保存。** 橡皮保留范围圈和笔迹高亮，没有跟随指针的文字浮层。

### 手势与书写区

| 操作 | 效果 |
| --- | --- |
| 单指轻触 → 加力 | 移动笔尖 → 书写或擦除 |
| 双指上下／左右滑动 | 滚动或平移 PDF，使用系统滚动事件与惯性 |
| 双指捏合 | 缩放 PDF |
| 三指移动 | 移动书写框，包括双栏中间的页缝 |
| 大小滑块或 `[ / ]` | 等比例调整书写框，范围 40–600%，受可见视窗尺寸限制 |
| “铺满” | 书写框覆盖整个可见阅读区，再次点击恢复等比例模式 |
| “居中”或 `C` | 将书写框放到当前阅读视窗中央 |

“铺满”允许横纵使用不同映射比例；需要保持手写比例时用普通大小滑块。书写框大小与 PDF 缩放独立，调整书写框不会改变已有笔迹。

鼠标也能操作：点击放置书写框，左键拖动移框；滚轮滚动，中键或右键拖动平移。

### 画笔与橡皮

“笔设置”里可以调整轻压力度、落笔方式、减力收笔和平滑。默认力度门槛为 30，数值是设备原始信号单位，不是克数；向左更容易落笔。

- **减力收笔开启：** 减轻力度就结束当前笔画，继续移动定位。
- **减力收笔关闭：** 加力起笔后持续书写，直到抬手。
- **轻触即写模式：** 单指触摸直接书写，按住 ⌘ 可以只预览位置。
- **橡皮：** 轻压模式下轻触时橙色高亮命中的完整笔画，加力后红色高亮本次待擦笔画，收笔后删除；`⌘Z` 一次恢复本次擦除。圈内重叠笔画会一起选中。

支持蓝、黑、红、绿、紫和自定义颜色。颜色、力度、减力收笔和平滑设置会记住；换颜色和修改平滑只影响新笔画。

## 快捷键

| 按键 | 操作 | 按键 | 操作 |
| --- | --- | --- | --- |
| `Shift` 单按松开 | 暂停／继续批注 | `X` | 切换画笔／橡皮 |
| `Esc` | 返回阅读 | `C` | 书写框居中 |
| `[` / `]` | 书写框缩小／放大 10% | `1`–`5` | 蓝／黑／红／绿／紫 |
| `⌘O` | 打开 PDF | `⌘N` | 新建空白画布 |
| `⌘S` | 保存 | `⇧⌘S` | 另存为 |
| `⌘Z` | 撤销 | `⇧⌘Z` | 重做 |
| `⌘W` | 关闭文档 | `⌘Q` | 退出应用 |

X、颜色、大小和居中操作不会自动开启批注。输入框中不触发工具快捷键，Shift 组合键也不会切换批注。点击工具栏的问号可随时查看操作说明。

## 保存规则

**PDF 页面内的笔迹会保存；页缝和页面外的笔迹只保留在当前会话。**

书写框固定在阅读视窗中，笔迹随 PDF 滚动和缩放。保存时，仅将实际落在 PDF 页面内的部分导出为标准矢量批注，可在系统“预览”等阅读器中打开。保存不会清除当前画布，但关闭后页外笔迹不会恢复。

页外笔迹同样支持擦除、撤销和重做。单双栏切换会重新排版页面，页外笔迹跟随起笔时的参考页移动。

退出或关闭文档时，未保存内容会触发保存提示。关闭最后一个文档或取消启动文件选择会退出应用。更新后可在窗口标题或“关于 TouchPDF / 当前版本…”中确认版本与运行路径。

## 使用须知

- 多指操作结束后，全部抬手再继续单指书写，避免误落笔；系统三指手势可能与移框冲突。
- 批注触摸期间固定系统箭头，包括外接鼠标；全部抬手、暂停或应用失焦后恢复。
- 真实触控板的力度、惯性和捏合体验因设备而异，可先在空白画布上调整力度。

## 从源码构建

需要 Xcode Command Line Tools，无第三方运行时依赖。

```sh
git clone https://github.com/lux-666/TouchPDF.git
cd TouchPDF
zsh build.sh
open dist/TouchPDF.app
```

打包与自检：

```sh
zsh package.sh
./dist/TouchPDF.app/Contents/MacOS/TouchPDF --self-test /tmp/touchpdf-check.pdf
```

也可以从“帮助 → 运行自检”执行检查，结果写入 `~/Library/Application Support/TouchPDF/Checks/`，不修改当前文档。回归检查覆盖输入状态、跨页画布、橡皮反馈、撤销和 PDF 保存重开，不能替代真实触控板试用。

<details>
<summary>实现与兼容性</summary>

轻触即写使用公开的 `NSTouch.normalizedPosition`。轻压模式通过小型 C 桥接动态加载私有 `MultitouchSupport.framework`，读取手指位置与力度相关字段，使用不同起笔／收笔门槛抑制临界抖动。私有接口对未来 macOS 的兼容性没有保证，也不适用于正常 Mac App Store 上架。

TouchPDF 笔迹使用按显示器像素倍率绘制的覆盖层，保存时在独立文档副本中重建矢量批注外观。输入不依赖鼠标坐标、不模拟左键、不修改系统触感或手势设置。原始输入仅由前台文档处理，不记录其他应用的输入。

</details>
